## 📖 ОПИСАНИЕ ПРОЕКТА

**Королевские Жалюзи** - это премиальная платформа для производства и продажи элитных жалюзи. С 2015 года мы создаем идеальный микроклимат в домах и офисах наших клиентов. Наше приложение представляет собой полнофункциональную CRM-систему с интеграцией WhatsApp и современным адаптивным дизайном.

> *"Мы не просто продаем жалюзи - мы создаем королевский комфорт"*

### 🎯 Ключевые особенности:
- 📱 Полностью адаптивный дизайн (Mobile First)
- 🖼️ Мультимедиа галерея с поддержкой множественных изображений
- 🤝 Интеграция WhatsApp для мгновенных заказов
- 📊 Расширенная админ панель с аналитикой
- 📈 Экспорт заказов в Excel с редактируемыми ячейками
- 🔄 Drag & Drop для управления изображениями
- 👥 Система установщиков и распределения заказов
- 🏷️ Категоризация товаров с фильтрацией

## 🛠 ТЕХНОЛОГИЧЕСКИЙ СТЕК

### Backend:
| Технология | Назначение |
|------------|------------|
| **FastAPI** | Современный веб-фреймворк |
| **SQLAlchemy** | ORM для работы с БД |
| **SQLite** | Легковесная база данных |
| **Jinja2** | Шаблонизатор |
| **Pydantic** | Валидация данных |

### Frontend:
| Технология | Назначение |
|------------|------------|
| **TailwindCSS** | Утилитарный CSS-фреймворк |
| **Font Awesome 6** | Иконки |
| **AOS** | Анимации при скролле |
| **GSAP** | Профессиональные анимации |
| **Swiper** | Мобильные свайп-галереи |
| **Chart.js** | Графики и диаграммы |

### Интеграции:
- 📱 **WhatsApp API** - для мгновенных заказов
- 📊 **OpenPyXL** - работа с Excel файлами
- 📈 **Pandas** - анализ данных
